# Stella ST — Página de recaudación

## Archivos

- index.html → estructura de la página
- style.css → diseño y estilos
- script.js → alias, barra de progreso y botones

## Personalización rápida

Abrí `script.js` y modificá:

const CONFIG = {
  alias: "STELLA.PROYECTO",
  recaudado: 126000,
  objetivo: 300000
};

También podés editar directamente los textos de `index.html`.

## Publicación

Subí los tres archivos a cualquier hosting estático. La página no necesita PHP, MySQL ni servidor.

Una vez publicada, usá la URL de la página para crear el QR del evento.
